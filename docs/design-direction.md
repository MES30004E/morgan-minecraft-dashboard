# Frontend direction

The requested Aternos-inspired hierarchy supplies the functional reference: clear
server identity, account access and operational status. Original visual direction:
forest-black workspace, moss-green primary actions, restrained bordered surfaces,
fixed desktop navigation and a compact mobile brand header. No borrowed brand art.

Refero research was attempted but requires a paid subscription. No upgrade was
made. Its bundled craft guide informs labels, keyboard focus rings, 44px targets,
semantic controls and explicit request states. Green is reserved for action and
brand emphasis; unavailable agent state uses neutral text, never a false green dot.

Initial frontend is an account application connected to Supabase, not a simulated
server dashboard. Operational pages will be introduced with their tested data APIs.
