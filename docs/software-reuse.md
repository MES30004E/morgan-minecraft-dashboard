Activity does not prove absence of vulnerabilities; published advisory samples are not a comprehensive security audit.

## Selected UI reference lock

Primary layout: official shadcn **sidebar-07**, an inset workspace with a restrained collapsible sidebar and grouped navigation. Preserve its compact header, consistent navigation rhythm and mobile Sheet behavior. Secondary functional references: Pterodactyl's console-first server view and MCSManager's explicit per-instance context. Original application content, names, permissions and routes replace all sample/demo entries.

Use a neutral zinc/charcoal dark default, a single restrained blue interactive accent, semantic green/amber/red only for state, a compact system font scale, 8px spacing rhythm and modest radii. No marketing hero, decorative gradients, fake trend lines, invented player data or emoji navigation. Light mode is an actual saved theme setting. CPU/memory history comes only from bounded real readings; empty states explain that the agent is not connected. Build success is not visual acceptance: desktop/mobile screenshots, keyboard/dialog checks and route/permission regression checks are required.

Refero research was attempted and returned NO_SUBSCRIPTION. No paid upgrade was requested; official free reference layouts and bundled craft guidance provide the reference lock instead.

## Connected design/build tools

The connected Floot, Lovable and Base44 tools primarily operate on their own application/project backends; using them to create a replacement would add a parallel app/hosting surface and undermine the existing-repository/Supabase constraint. Their tools were inspected, and no new project or paid resource was created. Canva/Figma design artifacts are optional handoff surfaces, not required runtime dependencies or replacements for accessible production components. The implementation reuses upstream open-source components directly in this repository.
